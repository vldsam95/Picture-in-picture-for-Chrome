# Picture-in-Picture for Chrome

תוסף Chrome במצב מפתח. פתחו סרטון, התחילו לנגן ולחצו על סמל התוסף או Alt+Shift+P.
הסרטון נפתח בחלון צף מעל שאר החלונות. אפשר לגרור אותו ולשנות גודל מהקצוות.
לחיצה נוספת או X סוגרת את החלון הצף. יש להשאיר את לשונית הסרטון פתוחה.

## התקנה

1. במחשב החדש הורידו את [קובצי התוסף כ-ZIP](https://github.com/vldsam95/Picture-in-picture-for-Chrome/archive/refs/heads/main.zip), או בחרו במאגר Code → Download ZIP.
2. חלצו את קובץ ה-ZIP לתיקייה קבועה במחשב.
3. בכרום פתחו `chrome://extensions` והפעילו **Developer mode / מצב מפתח**.
4. לחצו **Load unpacked / טעינת תוסף לא ארוז** ובחרו את התיקייה שחולצה ובה נמצא `manifest.json`. אין לבחור בתיקיית `icons`.
5. בתפריט התוספים של Chrome הצמידו את Picture to Picture לסרגל הכלים.

יש לשמור את התיקייה במחשב גם לאחר ההתקנה. התקנה במצב מפתח מתבצעת בנפרד בכל מחשב.

## עדכון

הורידו את הגרסה המעודכנת, חלצו והעתיקו את הקבצים לתיקיית ההתקנה הקיימת, ואז לחצו על כפתור הטעינה מחדש בכרטיס התוסף ב-`chrome://extensions`.

אם קיצור המקלדת אינו פועל, אפשר להגדירו ב-`chrome://extensions/shortcuts`.

הרשאות scripting ו-activeTab מפעילות את התוסף בלחיצה. גישה לעמודי HTTP/HTTPS מאפשרת איתור וידאו גם בנגנים משובצים ממקור אחר. אין סקריפטים שרצים אוטומטית, איסוף מידע או פניות רשת.

התוסף משתמש בחלון Picture-in-Picture המובנה בכרום. מגבלות אתר, נגן, iframe או מדיניות דפדפן עלולות למנוע שימוש בחלק מהסרטונים. עמודי chrome:// וחנות התוספים אינם נתמכים.
